💰 工资计算器

基于排班的工资计算工具，支持手动/单月/多月模式，含五险一金与个税

React 19 Tailwind CSS v4 TypeScript Vite
GitHub →

📋 功能

✏️ 手动算薪

直接输入加班小时、B班小时、F班小时、夜班天数，即时计算税前/社保/个税/到手工资。默认值：A班72h + B班44h。

📅 单月计算

选择年月 + C班周几 + 班次，自动识别 A/B/F 班日与中国法定节假日。支持不加班标记、B班仅8h调休。

📊 多月批量

选择跨月日期区间，统一或每月单独配置 C班/班次，自动轮换白夜班。分页展示 + 汇总统计。

⚙️ 设置

底薪/岗位工资/全勤奖/绩效工资全局同步。个税起征点与税率可调。社保固定 442.80 元。

🔄 排班规则

班次定义加班计算
A 班普通工作日（周一至周五中非 C 班前日、非法定假日）3h × 1.5 倍时薪
B 班C 班前一天（默认 11h × 2 倍，可勾选仅 8h）11h(或8h) × 2 倍时薪
C 班休息日（可自选周几，默认周三）不排班
F 班法定节假日出勤11h × 3 倍时薪

时薪 = 底薪 ÷ 21.75 ÷ 8。夜班补贴 = 20元/出勤日。所有金额以"分"为内部单位运算，消除浮点误差。
